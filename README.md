# Cabina

Aplicación para Mac que proyecta cortometrajes e imágenes, uno tras otro, en muestras, festivales y cineclubes.

## Descargar

- **Versión de prueba (lo último):** https://github.com/danimqp/cabina/releases/download/prueba/Cabina.dmg
- **Versión estable:** https://github.com/danimqp/cabina/releases/download/estable/Cabina.dmg

Abre el archivo y arrastra Cabina a Aplicaciones.

**La primera vez** macOS avisará de que no puede verificar la app. Ve a Ajustes del Sistema > Privacidad y seguridad, baja hasta el aviso sobre Cabina y pulsa «Abrir igualmente». Solo hace falta una vez.

## Cómo se usa

1. Conecta el proyector como **pantalla extendida** (no duplicada).
2. Pulsa **Añadir** o arrastra tus vídeos e imágenes a la lista. Ordénalos arrastrando.
3. Pulsa **Abrir salida**: el proyector se queda en negro (o con tu imagen de fondo).
4. Pulsa **Lanzar** en la pieza que quieras proyectar. Cuando termina un vídeo, el proyector vuelve solo al fondo.
5. La lista se puede editar en todo momento, también mientras se proyecta.

El botón **NEGRO** tapa la pantalla al instante sin perder el punto del vídeo.

### Teclas

| Tecla | Acción |
| --- | --- |
| Espacio | Pausar o reanudar el vídeo |
| ⌘B | Poner o quitar negro |
| ⌘→ | Lanzar la siguiente pieza |
| ⌘↩ | Lanzar la pieza seleccionada |
| ⌘I | Añadir archivos |

### Formatos

Vídeo: MP4, MOV, M4V. Imagen: JPG, JPEG, PNG (respeta la transparencia, sobre negro).

La función se guarda sola y se recupera al volver a abrir Cabina. Los archivos no se copian: si mueves o borras uno, la lista lo marca y permite localizarlo de nuevo.
